# EECS 3311 Course Project — AskDB

AskDB is a natural-language data analyst. You import a SQLite database or CSV files, ask a question in plain English, and the agent plans a read-only query, checks it, runs it, and shows the SQL, the result, a chart, and a short summary whose numbers are checked against that result.

This repository is the EECS 3311 Fall 2026 course project. Stage 1 is the design. Implementation comes in Stage 2.
